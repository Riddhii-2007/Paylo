# Security Policy

## Supported Versions

Currently, only the main branch is supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it directly to the repository maintainer via a private GitHub issue or the contact email provided on their profile. Do not open a public issue.

## Data Privacy & Device Security

**Your data lives ONLY on your device.** 
This is a 100% local-first application. There is no backend database, no tracking, and no external analytics. 
Because your data is exclusively stored in your browser's IndexedDB, **if you clear your browser data or uninstall the PWA, your data will be permanently deleted.**

To protect your data:
1. Export backups regularly using the Settings > Backup section.
2. Keep your backups secure, especially if they are unencrypted.
3. Protect your phone with a strong passcode or biometrics.
